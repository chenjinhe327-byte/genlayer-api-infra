# GenLayer 外部 API 集成基础设施

让智能合约安全、私密地调用外部 API（天气、加密价格、社交媒体）

## 功能

✅ 安全 API 密钥管理（不上链）
✅ HTTP/HTTPS + JSON 解析
✅ GET/POST 请求支持
✅ 价格预言机（CoinGecko）
✅ 天气数据（OpenWeather）
✅ 社交媒体数据（Twitter/X）
✅ 数据源签名验证
✅ 自动重试、限流、熔断
✅ GenLayer Studio 友好

## 快速开始

npm install

# 配置 .env

npm run build
npm run deploy
